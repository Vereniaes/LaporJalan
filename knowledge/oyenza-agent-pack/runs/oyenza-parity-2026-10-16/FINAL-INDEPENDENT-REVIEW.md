## Source findings

- Camera mode is controlled by App and shared with Map3D. The earlier empty-response finding is resolved: App clears/ends inspection when selectedReport is null or removed by filtering. Coordinate validation is reused before report/CCTV marker, popup, geometry and camera creation. Active camera target distinguishes report/search/CCTV so a refreshed same-ID report can update its active location without overriding a newer search/CCTV target. These are improvements over the immutable before snapshot.
- Map3D orbit now uses easeTo with duration zero and around selectedReport coordinates rather than setBearing alone (lines 657-665). This preserves the selected anchor under the inspection offset. The loop is stopped by mode changes/stopMotion, tab hiding and unmount; its visibility listener is removed. App changes caused by filter/data removal close inspection. This source inspection supports the visible framing evidence; it is not an independent timing or leak measurement.
- manageCloseZoomLabels saves line/line-center symbol visibility, hides those layers at zoom >=22, and restores the saved visibility below that level. Its style.load/zoom listeners are removed by the returned cleanup; Map3D calls that cleanup before map.remove (lines 392-401). No new permanently hidden road-label state was identified in the reviewed lifecycle.
- DamageLayer shares the map canvas/context and leaves renderer.autoClear false. It disposes owned geometries/materials/renderer wrapper rather than losing or deleting the map context. The geometry Set prevents double disposal of the shared bowl geometry used by surface and wireframe. No forceContextLoss or whole-scene depth-disable shortcut was found in the custom layer. This is source review, not proof of total GPU or JavaScript memory reclamation.
- Data labels now distinguish estimated dimensions, illustrative shape, synthetic fixture dimensions, unavailable water data and static example CCTV. CameraReportModal increments a request token before file/image changes, aborts an older reader, and checks the token before publishing asynchronous results. The earlier file-reader overwrite path is guarded. CCTV uses snapshot images, source/time unverified labels and no LIVE badge in the examined states; its expanded native dialog restores focus through the shared dialog helper.
